# Design Direction

Create a premium LIGHT-MODE B2B SaaS aesthetic.

The website should feel:

- clean
- trustworthy
- financial
- modern
- technical
- enterprise-ready
- spacious

The design should communicate:

"Your ecommerce finances are organized and under control."

---

# Color System

Use light mode as the primary and only required mode.

Background:

- primary: white
- secondary: very light neutral gray

Text:

- primary: near-black
- secondary: muted gray
- tertiary: lighter gray

Surfaces:

- white cards
- subtle gray borders
- very soft shadows

Accent:

- DeepEcom brand color

Use the accent color primarily for:

- primary CTAs
- important numbers
- active states
- links
- charts
- selected navigation items

Do not use the accent color everywhere.

---

# Light Mode Rules

Avoid:

- pure black sections
- heavy dark gradients
- excessive glassmorphism
- strong shadows
- colorful backgrounds
- excessive gradients

Prefer:

- white space
- subtle gray backgrounds
- thin borders
- restrained shadows
- strong typography
- clean data visualization

---

# Cards

Cards should generally use:

background: white

border: subtle neutral gray

shadow: very soft

Avoid making every section a card.

---

# Dashboard

The dashboard should be a major visual element.

Use:

- white background
- light gray table borders
- dark text
- subtle status badges
- restrained chart colors
- clear hierarchy

The dashboard should look like a real financial SaaS product.

Example:

Revenue       ₹24.8L
Orders        18,429
Profit        ₹6.2L
Margin        25.1%

Use subtle colored indicators for:

Reconciled
Pending
Mismatch

Do not make the dashboard visually noisy.

---

# Hero

Use a bright, spacious hero.

Structure:

Eyebrow

Large dark headline

Supporting paragraph

Primary CTA + secondary CTA

Dashboard/product visualization

The dashboard can sit on a very light gray surface behind the main hero content.

---

# Sections

Alternate between:

white

and

very-light-gray

backgrounds.

Do not create strong visual breaks.

The entire page should feel like one continuous product experience.

---

# Typography

Use a modern sans-serif.

Hero:

56–76px desktop

36–48px mobile

Section headings:

40–56px desktop

30–40px mobile

Body:

16–19px

Keep typography dark and high contrast.

---

# Visual Style

The target feeling is:

premium fintech SaaS

NOT:

generic startup landing page

NOT:

AI landing page

NOT:

dark developer tool

NOT:

over-designed marketing website

The design should feel credible enough for a finance team to trust with their ecommerce data.
